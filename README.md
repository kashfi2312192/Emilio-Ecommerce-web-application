# 💎 Emilia – Jewellery E-Commerce Web Application

Emilia is a modern jewellery e-commerce web application developed as part of a Software Construction & Development (SCD) project. The application provides customers with an elegant online shopping experience, allowing them to explore jewellery collections, view product details, manage their shopping cart, and place orders through a clean and responsive interface.

---

## ✨ Features

* 🏠 Responsive and modern homepage
* 💍 Browse jewellery collections
* 🔍 Search and explore products
* 📄 Product details page
* 🛒 Shopping cart management
* 👤 User registration and login
* ❤️ Wishlist support
* 📦 Order placement
* 📱 Responsive design for desktop, tablet, and mobile devices
* 🎨 Clean and user-friendly interface

## 🚀 Getting Started

### Prerequisites

* PHP 8.x
* Composer
* Node.js & npm
* MySQL

### Installation

Clone the repository:

```bash
git clone https://github.com/kashfi2312192/Emilio-Ecommerce-web-application.git
```

Navigate to the project directory:

```bash
cd Emilio-Ecommerce-web-application/example-app
```

Install PHP dependencies:

```bash
composer install
```

Install JavaScript dependencies:

```bash
npm install
```

Copy the environment file:

```bash
cp .env.example .env
```

Generate the application key:

```bash
php artisan key:generate
```

Configure your database settings in the `.env` file.

Run database migrations:

```bash
php artisan migrate
```

Start the development server:

```bash
php artisan serve
```

In a separate terminal, start the Vite development server:

```bash
npm run dev
```

The application will be available at:

```text
http://127.0.0.1:8000
```
